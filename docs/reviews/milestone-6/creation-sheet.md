# Structure creation-sheet PDF review

## Export

1. Open or create a project with several Structure rows, including one longer
   than the others and at least one annotated count block.
2. Edit **Project** in the main header and save the project.
3. Choose **File → Export Creation Sheet PDF…** and save the file.
4. Open the PDF in a viewer and print it on Letter paper in landscape mode.

## What to assess

1. Confirm every page shows the project title, `.kro` filename, page number,
   and repeating 1–8 ruler at normal readable opacity.
2. Confirm the longest section fits horizontally and rows continue on later
   pages without clipping; page headers and rulers repeat.
3. Confirm row labels and calibrated timestamps remain readable.
4. Confirm blocks, counts, annotations, and count marks are present but faint
   enough that pencil or pen writing dominates them.
5. Confirm selection borders, playhead, grid Anchor, buttons, and other
   interactive UI state are absent.
6. Export unsaved work and confirm the file label reads `Unsaved project`.

This is a writable Structure reference, not acceptance of the future complete
choreography-sheet PDF or its page-layout controls.
