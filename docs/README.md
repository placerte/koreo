# Project documentation

Koreo's durable project artifacts are grouped by role:

- [`handoffs/`](handoffs/) — milestone-specific execution contracts;
- [`specifications/`](specifications/) — product and design checkpoints that
  provide context but do not authorize implementation;
- [`references/`](references/) — historical source material and non-binding
  visual references;
- [`archive/`](archive/) — superseded project material retained for
  provenance; and
- [`progress_tracker.csv`](progress_tracker.csv) — local status mirror for the
  hosted milestone and issue roadmap.

For current authority and precedence rules, see
[`AGENTS.md`](../AGENTS.md). Milestone 1 must be executed only from
[`handoffs/handoff_261011_1.md`](handoffs/handoff_261011_1.md).

The approved Milestone 2 execution contract is
[`handoffs/handoff_261011_2.md`](handoffs/handoff_261011_2.md).
