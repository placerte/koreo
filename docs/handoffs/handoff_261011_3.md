# Koreo Milestone 3 execution handoff — song structure rows

**Status:** Approved  
**Approval:** Owner answers in GitHub issue #18 on 2026-10-11  
**Authority:** Sole execution contract for the initial Milestone 3 slice

## Outcome

Provide a Structure panel where the song flows vertically as sequential
top-level section rows. Each row renders local beat blocks while retaining an
exact absolute beat interval.

## Binding behavior

- One row represents one independent top-level section.
- The first named generator is **AABA** and creates `Intro, A, A, B, A, Outro`.
- Generator defaults are editable: section duration defaults to 32 beats and
  displayed block size defaults to 8 beats. Generated rows are contiguous.
- Repeated labels are independent instances, not linked aliases.
- Each section has a base color selected from a predefined accessible palette.
  Adjacent rows rotate colors; sequential 8-count blocks alternate base and
  lighter derived shades. Palette themes are future work.
- A persistent blank row permits drawing a new section. Horizontal drag snaps
  to whole beats and creates a positive duration.
- Selecting a row permits exact label, duration, and base-color editing.
- Existing rows can be resized and deleted. New rows append contiguously;
  explicit gaps remain visible and are never silently removed.
- Variable positive durations and incomplete final blocks are valid. Short
  sections may be centered visually, with no timing meaning.
- This slice edits top-level structure only. Nested phrases, insert/delete
  ripple algorithms, choreography safeguards, undo/redo, and reusable named
  template libraries remain deferred.
- Final anchor/refinement UX remains deferred. After this panel is approved,
  its alternating 8-count backgrounds may be reused as a faint waveform
  calibration overlay.

## Architecture

- Structure generation and edits are pure, GUI-independent operations.
- Beats remain exact `Fraction` values and half-open intervals.
- UI rendering consumes immutable project state and emits explicit edit
  requests; it does not own hidden timing state.
- The framework-neutral behavior in
  `docs/specifications/ui_behavior_v1.md` is updated with every approved UX
  adjustment.

## Validation

- Generator produces the approved six independent rows with exact contiguous
  32-beat intervals and deterministic palette rotation.
- Append, relabel, resize, recolor, and delete preserve unrelated tracks,
  moves, audio/calibration, and exact beat values.
- Non-positive duration and unknown IDs fail atomically.
- GUI tests cover rendering, selection, generator application, and editing.
- Run `uv run pytest`, `uv run black --check .`, `uv run mypy .`, and
  `uv build`.

## Review boundary

This slice is ready for human review when the owner can generate AABA, inspect
one section per row with alternating 8-count shades, add/select/edit/resize/
delete top-level rows, and confirm the intended Excel-like vertical reading.
It does not complete all of Milestone 3.
